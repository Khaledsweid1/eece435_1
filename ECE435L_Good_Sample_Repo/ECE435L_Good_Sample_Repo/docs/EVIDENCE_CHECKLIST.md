# Student evidence checklist (do not fabricate)

These are **instructions for creating evidence**, not attached evidence. The sample repository intentionally contains no screenshots or staged HTTP output.

- [ ] Actual Postman request **and** response screenshot for implemented endpoints.
- [ ] Screenshot caption: full student name — API title — what the call does.
- [ ] Actual database record demonstrating persistence or update.
- [ ] Genuine successful and failed authentication requests.
- [ ] Actual authorized and unauthorized requests; unauthorized attempts show rejected status.
- [ ] Invalid input test and clear error response (e.g., incorrect severity).
- [ ] Real GitHub repository URL, commit history, and each student's own commits.
- [ ] One team report with the named person responsible for each section/API.
- [ ] Importable Postman collection and clear instructions.
- [ ] References and disclosure of AI assistance, if applicable.

The course requires **nine services** overall and detailed report/database/authentication/deliverable coverage; this sample only demonstrates *how to organize and evidence* a limited slice.
